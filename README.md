# IQ Fitness website

Static website for iq-fitness.co.uk, built by Ladega Studio.

- `index.html` – the homepage
- `images/` – photos and logo
- `.github/workflows/deploy.yml` – publishes the site to the live hosting

## Working on the site

1. Clone the repo and create a branch for your change.
2. Preview by opening `index.html` in a browser.
3. Push your branch and open a pull request into `main`.
4. Once it's reviewed and merged, the site owner publishes it.

## Publishing

GitHub → Actions → "Deploy to live site" → Run workflow. This uploads the current `main` branch to the live site.

Anything in square brackets, such as `[Coach name]`, is a placeholder waiting for details from the client.
